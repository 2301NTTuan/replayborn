## Animation

Eight illustrated poses in a 4-column, 2-row atlas. Runtime states: idle (pose 0), run (poses 1–2), windup (3), attack (4), hurt (5), death (6–7). Left-facing frames are mirrored. Windup starts in the last 0.45 seconds before a boss skill; release holds the attack pose for 0.3 seconds. Spawn fades in; death collapses and fades out over 0.42 seconds. The final victory waits for the last boss death animation.

## Generation provenance

Created using the built-in imagegen tool. Each initial generation had no external image reference. Layout corrections use only the corresponding generated sheet as their reference. No franchise, artist, or existing character was requested. This generation trail is evidence of origin, not a legal clearance guarantee.

Final project assets live in `assets/original_v1/bosses/`. Original and intermediate files remain at the generator output location. Each atlas was visually inspected and rendered in Godot for checking the cell boundaries.
